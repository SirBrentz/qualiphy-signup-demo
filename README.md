# Qualiphy clinic signup demo

Clickable demo of a proposed clinic signup and setup flow. Fake clinic data only; nothing is saved or sent to Qualiphy.

Open the live page: https://sirbrentz.github.io/qualiphy-signup-demo/

- Progress is kept only in your browser tab. Close the tab, or use **Start over**, to begin again.
- **Fill sample** jumps to the setup questions with an example clinic already entered.
- Sample NPI that passes verification: 1234567893.
- Address search uses OpenStreetMap Nominatim for this demo (data (c) OpenStreetMap contributors). A production build would use a licensed address service behind the same screen.
